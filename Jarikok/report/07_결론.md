# Ⅲ-7. 결론

> 담당: 함준석 (총괄 PM · 기술 공정 설계)

대경선은 2량 1편성, 총 296명 중 좌석이 78석뿐인 열차다. 통학·출퇴근 시간에는 좌석이 늘 부족하지만, 지금은 잔여 좌석 정보가 전혀 제공되지 않아 승객이 흔들리는 열차 칸 사이를 직접 걸어 다니며 빈자리를 찾아야 한다. 게다가 옆자리에 가방을 올려두거나 혼자 두 칸을 차지한 승객 때문에 자리가 비어 있어도 앉지 못하는 일이 반복된다. 좌석 수 자체를 늘릴 수 없는 상황에서 필요한 것은 "빈자리가 있다/없다"를 넘어, **지금 비어 있는 자리, 곧 비게 될 자리, 짐 때문에 막혀 있는 자리**를 정확히 알려주는 정보다.

이에 본 조는 **좌석 상태 감지 센서(압력·정전용량·CCTV) + 기차 Wi-Fi 웹 시트 모식도 = 자리콕 웹(Web)** 이라는 1+1=NEW 1 방식의 제품을 제안하였다. 자리콕 웹은 감지(Sensing)–연산(Processing)–안내(Actuating)가 하나의 고리로 이어지는 폐루프(Closed-Loop) 구조로 동작한다.

첫째, **압력 True + 정전용량 True 는 사람, 압력 True + 정전용량 False 는 가방**이라는 단순한 진리표로 비매너 좌석을 구분하고, 위쪽 CCTV 의 YOLO 머리 추적으로 두꺼운 외투나 2칸 차지 같은 예외까지 교차 검증한다. 둘째, 압력 센서를 정논리(Active High)로 두어 **압력이 감지된 좌석에만 인공지능 연산을 수행**하므로 적은 연산 자원으로도 78석 전체를 1초마다 처리할 수 있다. 셋째, 승객이 내리기 전 엉덩이를 앞으로 옮기는 **무게중심 이동(CoP Shift)** 과 역마다 다른 하차율을 결합한 **역 간 하차 확률**로 "이번 역에서 곧 내릴 자리"와 "다음 역에서 생길 빈자리 수"를 미리 알려준다. 넷째, 별도의 앱 없이 **기차 Wi-Fi 에 접속하면 바로 열리는 웹 화면**에서 열차 시트 그림 위에 빈자리(파랑)·곧 내릴 자리(주황)·가방/2칸 차지 자리(빨강)를 실시간으로 찍어 준다.

특히 자리콕 웹은 한 번 만들고 끝나는 시스템이 아니다. 역에 정차할 때마다 "곧 내릴 것"이라고 예측한 좌석이 실제로 비었는지를 확인해 무게중심 판단 기준을 스스로 조정하고, 역별 하차율을 학습하며, 센서의 기준값도 자동으로 보정한다. **운행할수록 정확해지는 폐루프 구조**라는 점이 단순한 빈자리 표시판과 구별되는 가장 큰 차이점이다. 본 조는 이 판정 로직을 실제 C 코드로 구현하고, 같은 코드를 웹 화면에서 그대로 실행하는 시연용 웹사이트를 제작하여 진리표·하차 확률·피드백 규칙이 설계대로 작동함을 확인하였다.

자리콕 웹이 도입되면 승객은 칸을 옮겨 다니지 않고도 앉을 자리를 찾을 수 있어 매일 서서 이동하며 쌓이던 다리 통증과 피로를 줄일 수 있고, 가방 자리·2칸 차지 자리가 공개적으로 표시되어 열차 안 좌석 매너도 자연스럽게 개선될 것이다. 나아가 1단계 웹을 바탕으로 2단계에서는 좌석 하단 LED 스트립으로 빈자리를 파란색으로 밝히고 비매너 좌석에 시각적 신호(HRI)를 주며, 3단계에서는 같은 로직을 대학교 도서관의 '가방만 두고 자리 맡기(사석화)' 문제 해결로 확장할 수 있다.

**칸마다 헤맬 필요 없이, 빈자리와 곧 내릴 자리를 웹으로 한 번에.** 자리콕 웹은 좌석을 늘리지 않고도 대경선 78석을 더 공정하고 효율적으로 쓰게 만드는, 가장 현실적인 해결책이다.
